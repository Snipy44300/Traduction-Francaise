# Captain Tsubasa 3 - Koutei no Chousen - Traduction FR

Patch de traduction française v1.0 pour Captain Tsubasa 3 sur Super Nintendo.

## ROM  

Captain Tsubasa 3 - Koutei no Chousen (J) [!].smc

Région : Japon
Version : 1.0 

MD5 : 149887f784a31852c2e3f1357c9c1f5e

## Outil de patch

Floating IPS (Flips)  

## Instructions

1. Procurez-vous une copie de la ROM originale japonaise de Captain Tsubasa 3 (voir détails ci-dessus)  
2. Vérifiez que le MD5 de votre ROM correspond bien à celui indiqué
3. Ouvrez la ROM originale dans Flips
4. Parcourez et sélectionnez le fichier patch_fr_v1.0.bps
5. Cliquez sur "Apply Patch"
6. Sauvegardez la ROM patchée
7. Ouvrez la ROM traduite dans votre émulateur SNES favori  
8. Choisissez "Français" quand le jeu vous le demande
9. Profitez du jeu en français !

En cas de souci, vérifiez bien les informations de la ROM originale et du patch.
