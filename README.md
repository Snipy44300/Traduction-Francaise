# Traductions de jeux - Patchs FR

Collection de patchs de traduction française pour divers jeux rétro.

## Consoles

### Super Nintendo (SNES)

- Captain Tsubasa 3 - Koutei no Chousen
- Captain Tsubasa 4 - Pro no Rival Tachi

### Game Boy Advance (GBA)

- Dragon Ball Z - Team Training

## Instructions générales

1. Trouvez votre jeu dans le dossier correspondant à sa console
2. Vérifiez que vous avez la bonne ROM en comparant le MD5
3. Utilisez l'outil de patch recommandé pour appliquer le patch .bps à votre ROM
4. Jouez et appréciez le jeu en français !

Les instructions détaillées pour chaque jeu se trouvent dans son dossier.
